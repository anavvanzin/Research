## Achados — CRITICAL

**[C-01] GEMINI_API_KEY no bundle público (confirmado).**
Arquivo: `labs/iurisvision/vite.config.ts`, linha 11:
```ts
'process.env.GEMINI_API_KEY': JSON.stringify(env.GEMINI_API_KEY),
```
`loadEnv(mode, '.', '')` (linha 7) com 3º arg `''` carrega TODAS as envs, incluindo as que não começam com `VITE_`. A `define` substitui textualmente `process.env.GEMINI_API_KEY` no bundle — qualquer navegador que baixe `dist/assets/index-*.js` (2.1 MB) recebe a chave em plaintext.
Verificação: `grep -n GEMINI dist/assets/*.js` — a string não aparece porque o env local provavelmente estava vazio no build atual, mas o vetor está armado: basta a próxima build com env exportado (o README de labs/iurisvision descreve uso de Gemini).
**Remediação**:
1. Remover totalmente o bloco `define:` (linhas 10–12) — nunca inline secrets via Vite define.
2. Mover chamadas Gemini para um proxy server-side (Cloudflare Worker, já que o ecossistema usa Wrangler) ou Firebase Cloud Function. A key vive só no servidor.
3. Rodar `git log -p -- labs/iurisvision/vite.config.ts` e, se a chave chegou a ser commitada resolvida, fazer rotação imediata no GCP console (projeto `iconocracia`) + `git filter-repo` se necessário.
4. Substituir por variável pública ofuscada só se o endpoint proxy fizer rate-limit + auth.

**[C-02] `dangerouslySetInnerHTML` com HTML vindo de fetch.**
`apps/iconocracia-companion/src/app/main.jsx:1511`:
```jsx
<div ref={readerBodyRef} className="thesis-reader-body"
     onClick={handleReaderClick}
     dangerouslySetInnerHTML={{__html: activeDoc.html}}/>
```
`activeDoc.html` vem de `/api/corpus/...` (chamadas em `loadCorpusItems`, linhas 9–16) — fetch JSON cujo conteúdo HTML é injetado cru. Hoje a fonte é a própria API do Worker, mas:
- Se o JSON vier da tese markdown → HTML compilada pelo pipeline, e essa compilação permitir `<script>`, há XSS self-hosted.
- Não há sanitização (nem `DOMPurify`, nem `sanitize-html`).

**Remediação**: adicionar DOMPurify (ou o built-in `Sanitizer API` atrás de feature detection) antes da injeção, OU provar via test que o pipeline de compilação garante ausência de `<script>`/event handlers e documentar esse contrato no `SKILL.md` do companion.

**[C-03] Nenhuma Content-Security-Policy em surface alguma.**
Grep por `Content-Security-Policy` / `http-equiv` em todos os HTML servidos retornou vazio. Visual-essays carregam Chart.js do jsDelivr sem SRI hash (l. 7), fontes do Google sem integrity, companion public/index.html não declara CSP. Um XSS via [C-02] seria amplificado por ausência de `script-src 'self'` (Worker + `--assets`). O Atlas Iconométrico piora: carrega **Babel standalone** + React UMD + Recharts UMD de unpkg para compilação runtime de JSX (linhas 20–22), o que torna CSP estrito quase impossível sem refactor.

**Remediação**: adicionar meta `http-equiv="Content-Security-Policy"` nos 4 HTML, e no Worker injetar header CSP via response rewriter (já previsto no AGENTS.md do companion, seção "Cloudflare `[assets]`").

**[M-08] Performance do visual-essay — chamadas externas blocantes.**

**Recomendação**: adicionar `integrity="sha384-..."` + `crossorigin="anonymous"` no script Chart.js; preload dos 2 woff2 mais usados; mover script para antes de `</body>` com `defer`.
