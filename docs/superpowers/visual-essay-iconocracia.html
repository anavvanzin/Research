Padrões iconométricos e arquivo

Análise multidimensional de 145 alegorias jurídicas — como o arquivo interpreta os padrões que o index encontra

Ana Vanzin · Hermes Agent · 4 notebooks · 145 artefatos · 10 indicadores

O score composto de ENDURECIMENTO — média simples dos 10 indicadores — é o número central da tese. Ele resume cada artefato do corpus em um único valor entre 0 e 3. Mas o que acontece quando olhamos por trás do número?

O problema: O score composto trata os 10 indicadores como se fossem uma coisa só. A análise de componentes principais revela que eles não são.

O que isto revela

Normativo (1,82 / 1,82): maximiza o registro cromático — padronização visual, redução cromática. Moedas, selos, papel-moeda.

Militar (1,80 / 1,80): maximiza o registro burocrático — multiplicação serial, inscrição estatal. Cartazes de guerra, emissões monetárias.

São duas estratégias visuais distintas que o composite esconde porque convergem no mesmo número.

Cromia e materialidade: o que o index encontra

A PCA identificou três componentes com autovalor > 1. PC3 (9,6% da variância) é dominado quase inteiramente pela monocromatização (loading = 0,87). O index revela um padrão real — e levanta a pergunta que só o arquivo pode responder.

O teste crítico é preciso: dentro do mesmo meio material, monocromatização e endurecimento correlacionam?

Caso brasileiro: BR-016 vs. BR-005 — o index encontrou, o arquivo vai resolver

BR-016 (Alegoria da República, 1896, pintura): endurecimento core = 2,12, monocromatização = 0,0. BR-005 (Décio Villares, 1900): core = 1,12, mono = 0,0. Ambos têm mono = 0 porque pinturas são policromáticas — o index detecta a ausência de variação cromática, mas não pode determinar se ela é affordance de suporte ou escolha estratégica. Essa é exatamente a pergunta que o arquivo decide.

Figura 2 — Correlação entre monocromatização e ENDURECIMENTO core: no corpus completo vs. dentro de gravuras. Padrão encontrado pelo index — arquivo decide o que significa por dentro de cada meio.

ρ = −0,01

Dentro do mesmo meio, correlação nula (p = 0,92). O index não pode distinguir cromia estratégica de affordance material — essa pergunta pertence ao arquivo.

O que o index encontra — corpus

ρ = 0,27

Correlação aparente (p = 0,001) no corpus completo. O index detecta o padrão. O arquivo determina se ele é escolha ou consequência de meio.

O que o index encontra — moedas

mono = 3,6

Monocromatização máxima em todas as moedas do corpus. O padrão é absoluto. O arquivo vai dizer: era a única opção ou uma decisão de regime?

O que o arquivo decide

O index encontra o padrão: a monocromia estatal varia por meio, por período, por regime — e a variação não é trivial.

Para cada item com forte divergência entre ENDURECIMENTO core e registro cromático, a resposta sobre escolha estratégica vs. affordance material está nos arquivos de produção, nos catálogos de impressão, nas decisões editoriais. O index não pode substituir essa pesquisa — ele aponta onde ela precisa ir.

O registro cromático deve ser reportado como descriptor suplementar, não como variável autônoma de ENDURECIMENTO. O arquivo é a autoridade interpretativa: para cada alegoria monocromática, a pesquisa arquivística vai determinar se houve alternativa cromática disponível e se sua ausência foi escolha de regime.

A evolução temporal: quando endurece?

O corpus concentra-se em três períodos. A análise temporal é ilustrativa — o corpus não é amostra aleatória; reflete disponibilidade em arquivos digitais.

Figura 4 — ENDURECIMENTO médio por década. Décadas com n < 3 omitiram barras de erro. Tendência ilustrativa — viés de seleção não controlado.

O pico dos anos 1910s (n = 32, 23 militar) é o achado temporal mais robusto: a Primeira Guerra Mundial gerou uma produção massiva de alegorias jurídicas femininas em formato de cartaz e moeda, todas com alto registro burocrático.

Conclusão: o que o index encontra, o que o arquivo decide

O composite de 10 indicadores funciona — captura a dimensão geral de endurecimento que os regimes produzem de formas visualmente comparáveis. Mas ele deixa abertas três questões que só o circuito index→arquivo pode fechar:

  1. Normativo e militar são funcionalmente distintos. Mesmo com composite idêntico (1,82 vs. 1,80), operam por lógicas visuais diferentes — normativo pela redução cromática, militar pela multiplicação burocrática.
  2. A taxonomia de 4 regimes é empiricamente sólida. Clustering não-supervisionada reproduz a estrutura com alta concordância. Mas a divisão mais fundamental é binária: alegorias capturadas pela lógica de Estado vs. alegorias operando fora ou contra ela.
  3. O arquivo é a autoridade interpretativa do registro cromático. O index iconométrico levanta a questão — a monocromatização varia por meio, por período, por regime. Para cada item com divergência forte entre ENDURECIMENTO core e registro cromático, o arquivo de produção é o tribunal final: foi escolha estratégica ou affordance material?
O arquivo como autoridade interpretativa O circuito: index → padrões → arquivo → interpretação. Sem o index, o arquivo não sabe onde olhar — quais itens têm divergência forte, quais períodos concentram a variação, quais meios quebram a correlação. Sem o arquivo, o index não sabe o que os padrões significam. A quantificação levanta a questão; a pesquisa arquivística decide.
